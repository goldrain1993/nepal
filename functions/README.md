# 네팔 홍수 × 엔트리 온라인 수행평가 (시범 기능)

이 폴더는 **AI 채점 서버만** 담습니다. 학생 웹 화면은 `nepal_assessment.js`에 있고, 기존 엔트리 코드/현황판은 변경하지 않는 별도 데이터 경로를 사용합니다.

## 수업 운영 원칙

- 기존 공지된 수행평가 기준 그대로 적용: 설계 30/25/20/15점, 구현 30/25/20/15점, 보고서 40/30/20/10점.
- 학생은 자신의 서술형 설계서·보고서를 임시 저장하고, 최종 제출 시 조별 엔트리 코드의 **서버 저장본**을 별도 사본으로 남깁니다.
- 학생의 최종 제출 이후에는 학생이 제출본을 수정할 수 없습니다. 기존 조별 엔트리 프로젝트는 영향받지 않습니다.
- AI 사전 피드백, 점수 미리보기 없음. 교사가 [AI 채점 요청]을 누를 때에만 API 호출. **AI 제안은 확정 점수가 아님**.
- AI 제안은 `/nepal-v27/private/assessments/aiReviews`, 교사 확정 점수는 별도의 `reviews`에 저장하고 학생에게 공개하지 않습니다.
- 최초에는 학생 버튼이 숨겨집니다. 교사 전용 수행평가 화면에서 명시적으로 [학생 제출 열기]를 눌러 공개합니다.

## Firebase 연결 (관리자 작업)

⚠️ 이 문서대로 실행하기 전에 학교·교육청의 개인정보 처리 및 외부 AI 서비스 활용 지침, 평가 계획을 확인하세요. 실제 학급 데이터에 곧바로 적용하지 말고 테스트 계정과 모의 답안으로 먼저 점검하세요.

1. Firebase 콘솔에서 Realtime Database 규칙을 기존 `firebase.rules.json` 최신 버전으로 게시합니다. **규칙 변경 전 기존 규칙을 백업**하세요.
2. 등록 교사 계정으로 현황판 → 수행평가에 들어가 학생 제출 기능이 닫혀 있는지 확인합니다.
3. 학생 테스트 계정으로 임시 저장·최종 제출·다시 로그인하여 제출본 잠금이 유지되는지 확인합니다.
4. 교사 화면에서 제출본을 보고 [교사 점수 저장]을 확인합니다.
5. 실제 수업 시작 직전 [학생 제출 열기]를 눌러 공개합니다.

CLI에서 규칙을 게시하는 대안(프로젝트 연결이 정확히 되었을 때만 사용):

```bash
firebase login
firebase use --add
firebase deploy --only database
```

`firebase.json`은 이 저장소 루트에 있습니다. GitHub Pages 커밋만으로 Firebase 규칙이 자동 게시되지는 않습니다.

## AI 1차 채점 서버 (선택 사항 — 실제 비용 발생 가능)

Firebase Blaze 요금제와 승인된 OpenAI API 계정이 필요합니다. **코드를 GitHub에 올린 것만으로 Cloud Functions가 배포되거나 AI 요금이 청구되지는 않습니다.**

```bash
cd functions
npm install
cd ..
firebase functions:secrets:set OPENAI_API_KEY
firebase deploy --only functions:gradeNepalAssessment
```

- OPENAI_API_KEY를 웹 HTML, JS, GitHub 파일, 채팅에 기록하지 마세요.
- Firebase `gradeNepalAssessment`는 지정 교사 UID·Google 계정만 호출하도록 검사합니다.
- AI 결과는 1명당 한 번만 생성하여 캐시하므로 반복 호출 비용을 줄입니다.
- 입력에서 이메일·휴대전화 형식을 제거하고 실명 식별자는 직접 전송하지 않도록 구성했으나 자유 서술에 적힌 개인정보가 완전히 제거되는 것은 아닙니다. **사전 기관 검토가 필요합니다.**
- 구현 점수는 정적 코드와 참고 기록을 기반으로 **제안**합니다. 반드시 교사가 실제 실행과 학생 개인 기여를 확인해야 합니다.
- 학생에게는 AI 피드백이나 점수를 공개하지 않습니다.
- 비용 제어: Cloud Billing 예산 알림(알림은 자동 차단 아님), API 사용 한도, 함수 최대 인스턴스 2·동시 실행 1 설정. 실제로 학생 자료를 전송하기 전 학교의 허가 확인.

## 시험 시나리오

1. 수행평가 비공개 상태에서 학생에게 버튼 미표시
2. 교사가 학생 제출 공개 후 해당 반·조에서 학생 개별 입력 양식 확인
3. 임시 저장 → 새로고침 → 내용 복원
4. 저장되지 않은 코드라면 최종 제출 차단
5. 최종 제출 → 학생 재제출 불가 / 원래 엔트리 블록 유지
6. 다른 학생의 제출물 및 교사 점수 접근 권한 거부
7. 교사 제출 현황·코드 JSON 사본·세 단계 점수 저장
8. AI 서버 배포 후 교사 한 명의 **가상 답안**으로만 호출 시험

실제 Firebase와 OpenAI를 이용한 통합 테스트는 CLI 배포·규칙 게시가 완료되기 전에는 수행할 수 없습니다.
